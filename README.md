# Nikke/Nivel Arena Deck Builder

Un outil de construction de deck pour le TCG Nivel Arena (NIKKE, Stellar Blade, Epic Seven, etc.)

##  Règles de Construction de Deck

### Règles Officielles (Standard)

- **1 carte Leader** (obligatoire)
- **40 cartes** dans le deck (hors Leader)
- **Même IP uniquement** : Toutes les cartes doivent appartenir à la même franchise que le Leader
- **Maximum 3 exemplaires** par carte (même numéro d'identification)
- **Maximum 8 cartes [Trigger]** dans le deck
- Les cartes doivent respecter l'attribut/alignment du Leader

## 🎮 Fonctionnalités

- ✅ Validation automatique des règles
- ✅ Filtrage par IP (NIKKE, Stellar Blade, Epic Seven, etc.)
- ✅ Compteur de cartes en temps réel
- ✅ Détection des doublons (max 3)
- ✅ Gestion des cartes Trigger (max 8)
- ✅ Export/Import de decklists
- ✅ Recherche de cartes
