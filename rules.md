# Règles Officielles Nivel Arena

## Construction de Deck (Règlement Standard)

### Composition du Deck

1. **Carte Leader** : 1 carte obligatoire
   - Détermine l'IP autorisée dans le deck
   - Possède un attribut/alignment spécifique
   
2. **Deck Principal** : 40 cartes exactement
   - Doivent toutes être de la même IP que le Leader
   - Doivent respecter l'alignment du Leader

### Restrictions

#### Limite de Copies
- Maximum **3 exemplaires** d'une même carte (même numéro d'identification)
- Exception : Les cartes [Trigger] peuvent être ajoutées jusqu'à 8 exemplaires au total

#### Compatibilité IP
- ❌ Interdit de mélanger différentes IPs (ex: NIKKE + Stellar Blade)
- ✅ Toutes les cartes doivent correspondre à l'IP du Leader

#### Alignment/Attribut
- Les cartes doivent correspondre aux critères d'alignment du Leader
- Exemples d'alignments : Rouge, Bleu, Vert, etc.

### Format de Compétition

- **Deck** : 40 cartes + 1 Leader
- **Side deck** : Non autorisé en standard
- **Cartes autorisées** : Toutes les cartes coréennes publiées de l'IP sélectionnée

## Exemple de Deck Valide

**Leader** : Rapi (NIKKE)
**Deck** : 40 cartes NIKKE uniquement
- 3x Rapi SR
- 3x Rapi R
- 2x Modernia
- ... (32 autres cartes NIKKE)
- Maximum 8 cartes avec le mot-clé [Trigger]

## Exemple de Deck Invalide

**Leader** : Rapi (NIKKE)
**Deck** : 
- 20 cartes NIKKE
- 20 cartes Stellar Blade ❌
→ **Invalide** : Mélange d'IPs interdit
